# Synthetic NIN-shaped literals allowed in tracked files.
#
# `scripts/check-sample-pii.mjs` fails the build on any 8-character
# uppercase-alphanumeric literal in tracked source or docs that is not listed
# here. That is what stops a real NIN from a card sample being pasted into a doc
# or test — the samples themselves are gitignored, so nothing else catches it.
#
# Before adding a line, be sure the value is invented. If it came off a real
# card, replace it with a synthetic stand-in and purge it from git history
# instead. Keep the note; it is how the next person knows it is safe.
